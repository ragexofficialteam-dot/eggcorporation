DOMANDE FREQUENTI (FAQ)

Come posso entrare nei server di gioco?

Clicca sui pulsanti "Copia" nella sezione Server e incollali nel gioco rispettivo (Minecraft o Roblox).

Come entro nel team staff?

Controlla il canale #annunci nel nostro server Discord per le ultime aperture. Esse avvengono frequentemente a periodi definiti

Il server Minecraft supporta Bedrock?

Attualmente supportiamo Java Edition, ma stiamo lavorando per aggiungere il supporto cross-platform.

Come posso aiutare la community?

Già far parte della community, per noi, è un aiuto enorme!! Se desideri supportarci, potrai farlo acquistando i vantaggi VIP nei nostri server (dove preferisci), potenziando i nostri server oppure acquistando uno dei nostri servizi!.

Quali sono le modalità di pagamento?

I nostri servizi potranno essere pagati tramite paypal, oppure tramite boost al server discord principale. Supportiamo, inoltre, il pagamento in robux. Nel nostro server principale è presente un listino prezzi dettagliato, dove potrai verificare tu stesso il prezzo!

Come posso contattarvi?

Potrai contattarci tramite il nostro server ufficiale (aprendo un ticket), oppure direttamente alla nostra mail: ragexofficialteam@gmail.com (attenzione: eventuali e-mail troll, verranno cestinate senza risposta)
